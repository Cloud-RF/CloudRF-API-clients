# CloudRF JSON Templates

This directory contains JSON templates which can be combined with your client to simplify your request.

Each template contains core values which map to their respective API request to the CloudRF API.

## Template JSON schema

The authoritative JSON schema is located at template.schema.json

## Automatic generation with AI

Since October 2026, we're using Claude to make these with the associated SKILL.md file which automates tricky template settings.

Place SKILL.md in your .claude/skills/cloudrf-templates/ folder then run /cloudrf-templates in Claude's local CLI to use the skill.

Then tell it to make templates for a brochure :)
